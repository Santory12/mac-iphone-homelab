# Mac + iPhone: домашняя сеть через ZeroTier

Практическая инструкция: подключиться с iPhone к терминалу MacBook и слушать музыку с Mac mini. Компьютеры могут находиться дома за NAT провайдера. Проброс портов и отдельный VPS для этой схемы не нужны.

Версия **1.2**, 16 октября 2026 года. Все адреса, имена пользователей и идентификаторы заменены обозначениями. [История изменений](CHANGELOG.md).

В 1.2 добавлены SSH к Mac mini по отдельному ключу и запуск обработки непосредственно на mini, рядом с внешним диском. [Настройка и команды](docs/mac-mini.md). В репозитории есть универсальная команда запуска; сам инструмент восстановления конкретной музыкальной коллекции и его отчёты остаются приватными.

## Схема

```text
iPhone
  | ZeroTier (Wi-Fi или мобильный интернет)
  |
  +-- Termius -- SSH --> MacBook M1 / macOS Sequoia
  |                       +-- tmux --> Codex CLI
  |                       +-- Gemini CLI (отдельная проверка)
  |
  +-- VLC ----- SMB --> Mac mini Intel / macOS Catalina
                          +-- внешний накопитель с музыкой

MacBook -- SSH по ключу --> Mac mini
                           +-- Python / ffprobe --> локальная проверка музыки
```

На MacBook остаётся включён Red Shield VPN. На iPhone пользователь переключается между Red Shield и ZeroTier; в 1.2 эта схема сохраняется.

## Что понадобится

- ZeroTier на обоих Mac и iPhone, одна приватная сеть ZeroTier.
- Termius на iPhone для SSH; базового бесплатного доступа достаточно для этой схемы.
- VLC на iPhone для воспроизведения музыки по SMB.
- Включённый Remote Login на MacBook; File Sharing и, для запуска задач, Remote Login на Mac mini.
- `tmux` на MacBook для сохранения терминальных сессий при разрыве SSH.

По состоянию на дату инструкции бесплатный Personal ZeroTier включает 10 устройств и одну сеть для личного некоммерческого использования. Для трёх устройств платный тариф не требуется. Актуальные условия: [ZeroTier pricing](https://www.zerotier.com/pricing/), [Termius pricing](https://www.termius.com/pricing/).

## Обозначения

| Обозначение | Что подставить |
| --- | --- |
| `NETWORK_ID` | ID своей сети ZeroTier, 16 шестнадцатеричных символов |
| `MACBOOK_ZT_IP` | Адрес MacBook в ZeroTier Central |
| `MINI_ZT_IP` | Адрес Mac mini в ZeroTier Central |
| `MACBOOK_USER` | Короткое имя пользователя MacBook, команда `whoami` |
| `MINI_USER` | Короткое имя пользователя Mac mini |
| `MUSIC_SHARE` | Имя общей папки с музыкой |

В примерах заменяйте эти обозначения своими значениями. ID сети — идентификатор, а пароль для SSH/SMB принадлежит локальному пользователю соответствующего Mac.

## 1. Объединить устройства через ZeroTier

Создайте приватную сеть в ZeroTier Central. Установите ZeroTier на устройства и подключите каждое к одному Network ID. На Mac можно выполнить:

```sh
sudo zerotier-cli join NETWORK_ID
sudo zerotier-cli listnetworks
```

`200 join OK` означает, что клиент принял команду присоединения. Затем разрешите нужные устройства в Central: **Authorized**. Дождитесь назначенного ZT IP и статуса сети `OK` на Mac.

Проверка клиента:

```sh
sudo zerotier-cli info
sudo zerotier-cli peers
```

`Authorized` подтверждает разрешение со стороны контроллера, но доступность конкретного сервиса нужно проверять отдельно. Соединение через relay может работать с большей задержкой.

Для этой схемы оставьте разрешение управляемых адресов/маршрутов ZeroTier включённым. Не включайте маршрутизацию всего интернета или замену DNS через ZeroTier: это сеть для доступа к своим устройствам.

Документация: [Quickstart](https://docs.zerotier.com/quickstart/), [CLI](https://docs.zerotier.com/cli/).

## 2. Сохранить Red Shield на MacBook

В проверенной конфигурации в Red Shield на MacBook включили **Доступ к локальной сети**. После этого подключение к сервисам по ZeroTier заработало. **Kill Switch** и **Интернет только через VPN** в этой конфигурации были выключены.

Это описание конкретной рабочей конфигурации: сочетание версий, протоколов и сетей может влиять на результат. Отключённые функции блокировки не защищают от выхода в интернет при обрыве VPN. Не меняйте их автоматически, если такая защита нужна.

На iPhone для подключения домой отключите Red Shield и включите ZeroTier. Если Red Shield автоматически включается снова, проверьте его автоподключение. После завершения удалённого доступа можно переключиться обратно.

ZeroTier в этой схеме передаёт трафик к домашним устройствам. Обычный интернет iPhone не становится подключением через Red Shield.

Справка: [Red Shield: Kill Switch и VPN Only Access](https://redshieldvpn.org/en/help/apps/macos/killswitch).

## 3. Терминал MacBook с iPhone

На MacBook с английским интерфейсом:

1. **System Settings → General → Sharing → Remote Login**.
2. Включите Remote Login.
3. В **Allow access for → Only these users** добавьте локальную учётную запись, под которой будете подключаться. Имя iPhone к этому списку отношения не имеет.
4. Полный доступ к диску выдавайте только при необходимости для конкретных файлов.

В Termius создайте SSH-подключение:

| Поле | Значение |
| --- | --- |
| Host / Address | `MACBOOK_ZT_IP` |
| Port | `22` |
| Username | `MACBOOK_USER` |
| Password | Пароль этой учётной записи MacBook |

При первом подключении проверьте ключ сервера. При желании позднее замените вход по паролю входом по SSH-ключу.

Открытый терминал выполняет команды на MacBook. Устанавливать Codex или Gemini на iPhone для этой схемы не требуется.

Справка: [Apple: Remote Login](https://support.apple.com/en-au/guide/mac-help/mchlp1066/mac).

## 4. Сохранять терминальную сессию через tmux

Если Homebrew уже установлен, на MacBook:

```sh
brew install tmux
tmux new -A -s codex
```

Внутри tmux можно запустить CLI. Чтобы выбрать прежний разговор Codex:

```sh
codex resume
```

Обычный `codex` начинает новый разговор. История разговоров Codex и работающая терминальная сессия tmux — разные вещи.

После разрыва SSH снова подключитесь через Termius и выполните:

```sh
tmux new -A -s codex
```

Команда присоединит существующую сессию либо создаст её, если такой ещё нет. Для отсоединения без остановки программы: **Ctrl+B**, затем **D**. На MacBook можно открыть ту же сессию этой же командой.

Для Gemini можно использовать отдельную сессию:

```sh
tmux new -A -s gemini
gemini
```

Последний пример — следующий шаг, удалённый запуск Gemini отдельно не зафиксирован как проверенный. Если команда не найдена, проверьте `command -v gemini` и настройку PATH в SSH-оболочке.

tmux сохраняет процессы при отключении телефона, но не переживает перезагрузку Mac. Спящий или выключенный Mac может быть недоступен. Настройки сна в рамках этой версии не менялись.

Справка: [tmux Getting Started](https://github.com/tmux/tmux/wiki/Getting-Started).

## 5. Музыка с Mac mini в VLC

На Mac mini с Catalina: **System Preferences → Sharing → File Sharing**. Добавьте папку с музыкой или нужную папку внешнего диска. В **Options** включите SMB и доступ нужной учётной записи. Для прослушивания достаточно прав чтения на музыкальную папку.

В VLC на iPhone: **Browse → Connect to Server → SMB**. Названия могут зависеть от языка и версии приложения.

| Поле | Значение |
| --- | --- |
| Server | `MINI_ZT_IP` |
| Port | `445` |
| Username | `MINI_USER` |
| Password | Пароль этой учётной записи Mac mini |
| Workgroup | Оставить значение по умолчанию |

Откройте `MUSIC_SHARE` и выберите музыку. Для работы вне домашнего Wi-Fi используйте именно адрес ZeroTier. Накопитель должен быть подключён, а Mac mini — включён и доступен.

Справка: [VLC iOS: SMB](https://docs.videolan.me/vlc-ios-user/advanced/network_shares/smb.html).

## Проверка и диагностика

На другом Mac, подключённом к этой сети ZeroTier:

```sh
nc -vz -G 3 MACBOOK_ZT_IP 22
nc -vz -G 3 MINI_ZT_IP 22
nc -vz -G 3 MINI_ZT_IP 445
```

- `succeeded`: порт доступен; затем проверяйте логин, пароль и права.
- `Connection refused`: соединение отклонено; проверьте, включён ли нужный сервис и верен ли порт.
- Тайм-аут: проверьте питание, ZeroTier, назначенный IP, настройки VPN и firewall.

Для проверки мобильного доступа не нужно выходить из дома: отключите Wi-Fi в настройках iPhone, оставьте мобильный интернет, включите ZeroTier и заново откройте SSH и музыкальный файл.

## Приватность

В этом репозитории нет реальных IP-адресов, Network ID, логинов, паролей, ключей, скриншотов или истории CLI. Не добавляйте сюда конфиги ZeroTier, SSH, Gemini или Codex целиком. При адаптации инструкции храните реальные параметры отдельно.
