# История изменений

## 1.2 — 2026-10-16

- Добавлен доступ MacBook → Mac mini по отдельному SSH-ключу через ZeroTier.
- Описаны запуск Python-задач рядом с внешним диском и совместимость с Catalina / Python 3.8.
- Добавлена универсальная команда `scripts/mini-music` для вызова `check` и `status` на mini. Адрес и пользователь задаются в локальном SSH-конфиге.
- Добавлены пример SSH-конфига и диагностика случая, когда Remote Login на Catalina застрял при включении.
- Зафиксирован успешный локальный запуск проверки коллекции на mini; музыкальные файлы не изменены.
- Разделены подтверждённые возможности и оставшиеся задачи: фоновые процессы, меню, резервное копирование, тесты мобильного доступа и сна.

Внутренняя подготовка обозначалась как 1.1; отдельного публичного релиза 1.1 не было. Её завершённые изменения опубликованы в 1.2.

## 1.0 — 2026-10-15

- Первая инструкция по ZeroTier, SSH/Termius, tmux и VLC/SMB.
- Описана рабочая конфигурация с Red Shield на MacBook и переключением VPN на iPhone.

Публичный репозиторий содержит инструкции и универсальную команду запуска. Персональная логика восстановления альбомов, пути коллекции, отчёты, сетевые параметры и ключи не публикуются.
